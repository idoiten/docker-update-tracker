# brand/

Place `icon.png` here (and optionally `logo.png`) to give the
integration a proper icon in Home Assistant's UI - same convention
used across HA's custom integrations.

- `icon.png`: square, 256×256px recommended
- `logo.png`: optional, wider format, shown in some UI contexts

See https://developers.home-assistant.io/docs/creating_integration_manifest/#icons-and-logo
for current requirements.
